# GlobalOpinionQA-derived candidates

`global_opinions_binary_candidates.csv` is a filtered subset (661 questions with exactly two
substantive answer options) of the GlobalOpinionQA compilation released by Anthropic as the
Hugging Face dataset `Anthropic/llm_global_opinions` (Durmus et al., 2023, "Towards Measuring the
Representation of Subjective Global Opinions in Language Models"). That dataset is distributed under
the CC-BY-NC-SA-4.0 license; this derived file is redistributed under the same license, for
non-commercial research use, with attribution to the original authors. The full compilation is not
redistributed here and can be obtained from the Hugging Face dataset page.

The 15 opinion pairs selected from these candidates, with the mapping to the source question and
answer options, are in `../../opinion_pairs_globalopinionqa.csv`.
